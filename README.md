# Жайлау Шайқасы

Шахмат ережесімен ойналатын, бірақ фигуралары тірі ойын. Тақта шөп төселген жайлау, әр фигура өз қабілетімен жүреді және жауын өз анимациясымен құлатады.

| Фигура | Шахматта | Жүрісі | Құлату |
|---|---|---|---|
| Қоян | пешка | алға секіреді, қиғаш қағады | басына секіріп түседі |
| Жылқы | ат | «Г» әрпімен секіреді | тебеді |
| Жылан | піл | қиғаш сырғиды | шағады, жау еріп кетеді |
| Түйе | ладья | тіке екпіндейді | соғады, жау аспанға ұшады |
| Бүркіт | ферзь | кез келген бағытқа ұшады | тырнағымен көтеріп әкетеді |
| Батыр | король | бір қадам кез келген жаққа | қылышпен шабады |

## Мүмкіндіктер

- Ботқа қарсы немесе екі ойыншы режимі
- Шах, мат, тең ойын, жүрісті қайтару
- Қоян соңғы қатарға жетсе, Бүркітке айналады
- Рокировка мен en passant жоқ
